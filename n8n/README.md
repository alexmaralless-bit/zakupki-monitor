# Сценарии n8n для кнопки «В CRM»

Монитор отправляет выбранную закупку `POST`-запросом на вебхук n8n (схема `tender.v1`, пример ниже). Сценарий создаёт записи в CRM и отвечает JSON `{crm, external_id, url}`; ответ сохраняется в журнале отправок карточки, статус закупки становится «В CRM».

| Файл | Что делает |
|---|---|
| `amocrm.json` | amoCRM: сделка + компания (`/api/v4/leads/complex`), задача на дату окончания подачи, примечание со сводкой |
| `bitrix24.json` | Bitrix24: `crm.company.add`, `crm.deal.add`, `tasks.task.add` на дату окончания подачи |
| `universal.json` | Google Sheets (строка в таблицу) + сообщение в Telegram |

Во всех сценариях одна цепочка: **Вебхук** (POST, авторизация заголовком по желанию) -> **Маппинг** (Code) -> узлы CRM -> **Ответ монитору** (Respond to Webhook).

## Подключение

1. В n8n: Workflows -> Import from File, выберите нужный `.json`.
2. Откройте узел **Маппинг** и впишите в первой строке свои данные: поддомен amoCRM, адрес портала Bitrix24 или ссылку на таблицу.
3. Назначьте учётные данные по имени (в файлах хранятся только имена, ключей нет):
   - `Zakupki webhook secret` (Header Auth: имя заголовка `X-Webhook-Secret`, значение любое) для узла «Вебхук от монитора». Если секрет не нужен, выберите в узле Authentication: None.
   - `amoCRM OAuth2` (OAuth2 API), `Bitrix24 OAuth2` (OAuth2), `Google Sheets account`, `Telegram Bot`.
4. Включите сценарий (Active) и скопируйте **Production URL** вебхука, вида `http://localhost:5678/webhook/zakupki-amocrm`.
5. В мониторе: Настройки -> «CRM через n8n»: адрес вебхука, имя заголовка и значение секрета (то же, что в учётных данных n8n).

Для универсального сценария создайте в таблице лист «Закупки» с заголовками: Дата, Номер, Закон, Объект, Заказчик, ИНН, Цена, Подача до, Рейтинг, Профиль, Ссылка ЕИС, Заметка. В узле Telegram замените `ВАШ_CHAT_ID`.

Шаблоны собраны по документации API (amoCRM v4, Bitrix24 REST, узлы n8n). Названия учётных данных и типы узлов после импорта стоит проверить в вашей версии n8n; боевые CRM на этом этапе не подключались.

## Формат запроса `tender.v1`

```json
{
  "schema_version": "tender.v1",
  "reg_number": "32616430006",
  "law": 223,
  "method": "Конкурс в электронной форме ...",
  "object": "Выполнение предпроектных, проектных и изыскательских работ ...",
  "customer": {"name": "АО \"МОСОБЛГАЗ\"", "inn": "5032292612"},
  "price": 4838451.11,
  "currency": "RUB",
  "published_at": "2026-10-01",
  "updated_at": "2026-10-01",
  "deadline_at": "2026-10-09T12:00",
  "url": "https://zakupki.gov.ru/...",
  "profile": "Проектирование газопроводов",
  "rating": 86.0,
  "rating_breakdown": {"rules": [...], "ai": {...}},
  "ai": {"score": 73, "verdict": "...", "reasons": ["..."], "quotes": ["..."]},
  "user_note": "позвонить в понедельник"
}
```

`deadline_at` содержит время (МСК), если оно есть в карточке закупки, иначе только дату. Ответ вебхука: `{"crm": "amocrm", "external_id": "123", "url": "https://..."}`; любой ответ с кодом 2xx считается успешной отправкой.
